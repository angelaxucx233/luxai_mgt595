7 · Conversion Step 1 of 4

Describe Your PDF Slides

1 describe_slides.py
① Describe
② Outline
③ Build
④ Bake audio

Gemini vision reads each PDF page and writes a structured JSON catalog.

In: PDF in lectures/ · Out: lecture04_slide_descriptions.json

Step 1 — run from luxai_template/
python agents/describe_slides.py \
  --pdf "../lectures/MGT 403 - Lecture 04 - Binomial Distribution.pdf" \
  --json lecture04_slide_descriptions.json \
  --context "MGT 403 Lecture 04: Binomial Distribution"
Lux reads
your slides
8 · Conversion Step 2 of 4

Design the Interactive Outline

2 outline_lecture.py
① Describe
② Outline
③ Build
④ Bake audio

Instructional-design AI plans explain / problem / interactive slides — not a PDF clone.

In: lecture04_slide_descriptions.json · Out: lecture04_outline_refined.json (pass 1 + 2)

Step 2 — pass 1 + pass 2 in one command
python agents/outline_lecture.py \
  --input lecture04_slide_descriptions.json \
  --output lecture04_outline.json \
  --refined-output lecture04_outline_refined.json \
  --lecture-id lecture04 \
  --lecture-title "Binomial Distribution"
Lux plans
the lesson
9 · Conversion Step 3 of 4

Build the React Slide Deck

3 build_slides.py
① Describe
② Outline
③ Build
④ Bake audio

Outline → JavaScript slide deck in the React app.

In: lecture04_outline_refined.json · Out: src/data/lectures/lecture04Slides.js — then set available: true in the catalog.

Step 3 — generate the slide deck
python agents/build_slides.py \
  --outline lecture04_outline_refined.json \
  --lecture-id lecture04

# Then run the app:
npm run dev   → /course/mgt-403/lecture/04
Lux teaches
the class
